## PR Instructions
- Disclosure of AI use is required. Failure to disclose will result in the PR being rejected and the submitting user may be banned from creating future PRs.
- Title instructions: Include "[AI Generated]", "[AI Assisted]", or "[AI]" in the title.
- Description instructions: Include a clear AI use disclosure in the top or bottom of the description.

  Description disclosure example: "This PR includes AI generated code or other AI use. As part of this repo's rules, I am disclosing my use of AI in the creation of this PR."
